# Security Policy

## Supported Versions
Only the latest release (or the default branch) receives security fixes.

## Reporting a Vulnerability
Please do not open a public issue for security problems.

Report privately using GitHub's "Report a vulnerability" button
(Security tab of this repository), or email hello@arvind.codes.

Include:
- What the issue is and where it is
- Steps to reproduce
- Possible impact

You will get a reply within 7 days. Once fixed, the issue will be
disclosed in a GitHub Security Advisory, with credit to the reporter
if they want it.
